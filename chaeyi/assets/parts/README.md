# 아바타 부위 그림 규격

부위 그림은 **전부 같은 512×512 캔버스**에 그려져 있고, 겹치면 바로 맞아야 한다.
부위마다 잘라 놓으면 위치를 맞출 방법이 없다.

## 인형 몸의 좌표 (512 기준, 괄호는 1024 기준)

`body/base.png` 를 실측한 값이다. 새 부위를 받을 때 이 좌표를 그대로 불러 준다.

| 자리 | y | 좌우 x | 폭 |
|---|---|---|---|
| 정수리 | 41 (83) | — | — |
| 머리통 제일 넓은 곳 | 182 (365) | 148~363 (297~726) | 215 (430) |
| 목 | 246 (492) | 239~272 (478~545) | 34 (68) |
| 어깨 | 266 (532) | 210~301 (421~602) | 91 (182) |
| 허리 | 300 (600) | 189~321 (379~643) | 132 (265) |
| 다리 | 400 (800) | 203~308 (407~616) | 105 (186) |
| 발바닥 | 470 (940) | — | — |

가로 중심은 언제나 **x = 256 (512)** 이다.

얼굴이 보여야 하는 자리는 **x 176~335, y 149~243 (352~670, 298~487)** —
머리카락은 이 안을 덮으면 안 된다.

## 겹치는 순서

`avatar-render.js` 의 `LAYERS` 가 정한다.
`bg → hairBack → body → shoe → top → face → hairFront → acc`

## 색

칠은 **음영 없이 평평한 한 가지 색**이어야 한다. 그래야 밝기 비율만 옮겨서
다른 색으로 칠할 수 있다 (`tools/recolor` 참고). 검은 윤곽선은 밝기가 0 이라
저절로 검게 남는다. 머리 모양 7개 × 머리색 12개 = 84 가지가 그림 7장에서 나온다.

피부색 6가지도 `body/base.png` 한 장에서 나온다 — 살색 계열 픽셀만 옮기면
검은 눈과 윤곽선은 그대로 있는다.

## 받은 그림을 넣는 법

생성 AI 는 알파 채널을 못 만들어서 투명 대신 회색 체크무늬를 **그려서** 준다.
`tools/prep-part.py` 가 그 무늬를 지우고 512 로 줄여 저장한다.

```
python3 chaeyi/tools/prep-part.py 받은그림.png chaeyi/assets/parts/hair/pony.png
```

크기나 위치가 어긋나 오면 (그림 AI 는 캔버스 한가운데에 그리는 버릇이 있다)
얼굴을 덮어버린다. 그럴 땐 머리통 폭 430 에 맞추고 정수리를 y=83 에 놓으면
대개 맞는다.
