# 🦟 끈끈이 버그 잡기! — 보드게임 규칙서

> 가평 펜션 천장에 나타난 벌레들!  
> 끈끈이 트랩을 던져 가장 많이 잡는 사람이 왕!

---

## 👥 게임 정보

| 항목 | 내용 |
|------|------|
| 인원 | 2 ~ 4명 |
| 권장 연령 | 7세 이상 |
| 플레이 시간 | 20 ~ 40분 |
| 특징 | 타이밍, 전략, 행운 조합 |

| 구성품 | 수량 |
|--------|------|
| 게임판 (5×5 천장 그리드) | 1개 |

| 특수 카드 | 24장 |
| 점수 마커 (색별) | 4세트 |
| 정확도 원판 | 1개 |
| 6면 주사위 | 2개 |

## 🐛 벌레 종류

| 벌레 | 이름 | 점수 | 닷지값¹ | 토큰수 |
|------|------|------|---------|--------|
| 🦟 | 모기 | 1점 | 1 | 15개 |
| 🪰 | 파리 | 2점 | 2 | 10개 |
| 🐜 | 개미 | 2점 | 1 | 8개 |
| 🪳 | 바퀴벌레 | 3점 | 3 | 4개 |

> ¹ **닷지값**: 잡기 성공 후 주사위 굴려 닷지값 이하 나오면 벌레 도망 (6면 주사위 기준)

## 🃏 특수 카드 (24장)

| 카드 | 이름 | 효과 | 장수 |
|------|------|------|------|
| ⭐ | 슈퍼 끈끈이 | 이번 투척 무조건 성공, 닷지 없음 | 4 |
| 💥 | 끈끈이 폭탄 | 선택 칸 포함 3×3 범위 동시 공격 | 3 |
| 🔍 | 버그 탐지기 | 뒤집힌 벌레 토큰 전부 공개 | 4 |
| ⚡ | 연속 공격 | 이번 턴 2번 투척 가능 | 4 |
| 🍬 | 먹이 유인 | 벌레 1마리를 원하는 빈 칸으로 이동 | 4 |
| 🎭 | 훼이크! | 상대방 바로 다음 투척 닷지 +3 페널티 | 5 |

---

## 🏗️ 게임 준비

1. 게임판을 테이블 중앙에 놓는다 (이것이 펜션 천장!)
2. 벌레 토큰 **12개**를 뒤집어 섞은 후 그리드 칸에 무작위 배치  
   (일부는 뒤집은 채로 → 어떤 벌레인지 모름!)
3. 특수 카드를 잘 섞어 각 플레이어에게 **3장씩** 나눠준다
4. 기본 끈끈이 카드 각 **5장씩** 나눠준다
5. 가위바위보로 **첫 번째 플레이어** 결정

---

## 🎮 게임 진행

### 한 턴의 순서

```
① 카드 사용 (선택) → ② 칸 선언 → ③ 투척 판정 → ④ 닷지 판정 → ⑤ 다음 플레이어
```

#### ① 카드 사용 (선택)
- 투척 전에 특수 카드를 **1장** 사용할 수 있다
- 사용한 카드는 버림 더미에

#### ② 칸 선언
- 잡고 싶은 벌레가 있는 **칸 번호**를 말한다
- 비어있는 칸이나 이미 잡힌 칸은 선택 불가
- 뒤집힌 칸도 선택 가능 (잡고 나서 공개)

#### ③ 투척 판정 — 정확도 원판 사용

```
원판을 돌려 멈춘 구간에 따라:

  🟢 완벽! (25%)  → 명중 보장
  🟡 좋아요 (50%) → 명중
  🔴 아쉬움 (25%) → 빗나감, 버려진 끈끈이 카드 1장 소모
```

> **주사위 대체안**: 주사위 2개 합계  
> 9~12 = 완벽 / 5~8 = 명중 / 2~4 = 빗나감

#### ④ 닷지 판정 (명중 시만)
- 명중 성공 시, **6면 주사위 1개** 굴리기
- 결과가 벌레의 **닷지값 이하**면 → 벌레 도망! (랜덤 칸으로 이동)
- 닷지값 초과면 → 포획 성공! 토큰을 가져가고 점수 획득

#### ⑤ 다음 플레이어
- 왼쪽 플레이어에게 차례 이동

---

## 🔄 라운드 종료 및 새 벌레 등장

- 모든 플레이어가 1번씩 턴을 마치면 **1라운드 종료**
- 라운드 종료 시, 주사위 1개 굴려 **4 이상**이면 새 벌레 토큰 1개 랜덤 배치
- 전체 벌레가 모두 잡히면 즉시 새 벌레 **6마리** 보충

**점수 합산 후 가장 높은 플레이어 승리!**

## 🌟 보너스 점수

| 조건 | 보너스 |
|------|--------|
| 한 턴에 3마리 이상 포획 (폭탄 사용) | +3점 |
| 거미 🕷️ 포획 | 특수 카드 1장 추가 획득 |
| 3연속 포획 성공 (닷지 없이) | +2점 |
| 한 라운드에 가장 많이 포획 | "슈퍼 포획자" 칭호 +1점 |

## 💡 전략 팁

1. **고득점 노리기**: 거미·풍뎅이는 점수가 높지만 잡기 어려워요. ⭐ 슈퍼 끈끈이 카드와 함께 공략!
2. **뒤집힌 토큰**: 뒤집어둔 칸에 거미가 숨어있을 수도! 🔍 탐지기로 먼저 확인하세요.
3. **폭탄 타이밍**: 여러 벌레가 모인 구역에 💥 폭탄을 쓰면 대박!
4. **방해 전략**: 상대가 고득점 벌레 노릴 때 🎭 훼이크! 카드로 방해!
5. **먹이 유인**: 🍬 카드로 흩어진 벌레를 한곳으로 몰아서 폭탄 콤보!

## 🎲 빠른 룰 (어린이용 간소화)
