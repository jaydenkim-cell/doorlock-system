# 채이 수학 — 기획서

초등 2학년 채이를 위한 수학·영어 학습 앱. Duolingo와 말해보카를 참고하되,
**두 앱 모두 대상 연령이 채이보다 한참 위**라는 점에서 출발한다.
메커니즘을 그대로 옮기면 역효과가 나는 지점을 하나씩 갈아 끼웠다.

---

## 1. 전제

| 항목 | 결정 | 이유 |
|---|---|---|
| 범위 | **채이 전용 가족용** | 서버에 개인정보를 두지 않으므로 만 14세 미만 법정대리인 동의·앱심사·아동 카테고리 심사가 전부 불필요. 2주 안에 실사용 가능 |
| 형태 | **PWA** | 홈화면 설치·오프라인 동작. 앱심사 없이 즉시 수정 배포. 아이패드·안드로이드·PC 전부 커버 |
| 1차 과목 | **수학** | 문항을 규칙으로 무한 생성할 수 있다. 영어는 단어별 오디오·이미지가 필요해 공수 약 5배 |
| 저장 | **기기 안에만 (localStorage)** | 외부로 나가는 아이 데이터가 없음. 대신 유실 대비 백업 기능을 기본 탑재 |

## 2. 교육과정 앵커

2022 개정 교육과정 초1~2학년군 수학. 상세 매핑은 [`../data/curriculum.json`](../data/curriculum.json).

채이는 2학기 진입 시점이며, 2학기 단원은
네 자리 수 / **곱셈구구** / 길이(m·cm) / 시각과 시간 / 표와 그래프 / 규칙 찾기.

**1차 대상 2개:**

| 스킬 | 단원 | 왜 이걸 먼저 |
|---|---|---|
| **곱셈구구 (2~9단, 72문항)** | 2-2 · 2단원 | 2학기 최대 관문이자 이후 나눗셈·분수의 전제. 문항이 유한해 "얼마나 익혔나"를 정확히 잴 수 있다 |
| **받아올림·받아내림 (79문항)** | 2-1 · 3단원 | 1학기 내용이지만 계속 쓰이는 기초. 복습 트랙 |

시각과 시간, 길이, 표와 그래프는 3차. `curriculum.json`에 `status: "planned"`로 자리만 잡아 두었다.

## 5. 학습 설계

### 5.1 간격 반복 (Leitner)

```
오답            → box 1 로 강등 + 이 판 끝에 재출제
정답 + 느림     → box 유지        (정답이라고 다 아는 게 아니다. 손가락으로 세는 중)
정답 + 빠름     → box + 1
```

| box | 다음 복습까지 |
|---|---|
| 1 | 같은 세션 안에서 다시 |
| 2 | 1일 |
| 3 | 3일 |
| 4 | 7일 |
| 5 | 21일 |

**마스터 판정 = `box ≥ 4` 이면서 `평균 응답시간 ≤ 목표(기본 3초)`.**
오래 기억하고 있고, 자동으로 나오는 상태를 둘 다 만족해야 한다.

### 5.2 문항 선택

한 판(기본 10문항)을 이 순서로 채운다.

1. 복습할 때가 된 것 (`dueAt` 지남, 오래 밀린 것부터)
2. 새 항목 — **한 판에 최대 3개.** 한꺼번에 몰아주면 초2는 무너진다
3. 약한 것 (정답률 70% 미만 또는 목표 시간 초과)
4. 그래도 모자라면 박스가 낮은 것부터

> 첫날처럼 복습할 것도 배운 것도 없으면 4번에서 새 항목으로 판을 채운다.
> 그때는 전부 보기 4개짜리로 나가므로 부담이 크지 않다.

### 5.3 오답 선지는 무작위가 아니다

정답 근처의 아무 숫자를 넣으면 "틀렸다"는 사실만 남는다.
실제 혼동 패턴으로 만들어야 **아이가 고른 오답이 곧 진단 데이터**가 된다.

**곱셈구구**
- 인접한 곱 — 7×8을 7×7 / 7×9로 (구구단을 외다가 한 칸 밀림)
- 반대쪽 인접 — 6×8 / 8×8
- 자릿수 뒤집기 — 56 → 65
- 덧셈 오적용 — 7+8 = 15

**받아올림·받아내림** (이 나이대 최다 실수는 단연 자리올림 누락)
- 받아올림 빠뜨림 — 37+48 → 75
- 받아내림 빠뜨림 — 45−18 → 37
- 자리마다 큰 수에서 작은 수를 뺌 — 45−18 → 33

부모 화면에는 "7×8을 세 번 틀림"이 아니라 **"7×8을 7×7과 헷갈림 (한 칸 앞)"** 으로 표시된다.

### 5.4 factKey 설계

덧셈·뺄셈에서 "37+48" 같은 구체적 문제를 키로 삼으면 경우의 수가 너무 많아 간격 반복이 작동하지 않는다.
그래서 키는 **실제로 걸려 넘어지는 지점인 일의 자리 계산**으로 잡는다.

```
37 + 48  →  핵심은 7+8  (받아올림)
45 − 18  →  핵심은 15−8 (받아내림)
```

같은 `7+8`을 여러 옷을 입혀 반복시키면서 숙련도는 하나로 추적한다.

## 6. 게임화 (초2 친화 버전)

- **하트 없음.** 틀리면 정답을 보여주고 이 판 끝에 한 번 더 낸다
- **구구단 지도** — 2~9단 8칸이 숙련도만큼 아래에서 차오른다. 100%가 되면 초록 + ⭐️
- **주간 도장** — 월~일 7칸, 목표 4일. 리셋 없음, 매주 새로 시작
- **보상** — 세션 완주 = 별 / 한 단 마스터 = 스티커 / 자기 최고 응답시간 갱신 = ⚡️
- **정답은 0.85초 만에 자동으로 넘어간다.** 리듬이 끊기면 재미가 사라진다
- **오답은 아이가 직접 눌러서 넘어간다.** 정답을 한 번은 보고 지나가도록

```js

           maxNewPerSession, sound, haptics, parentPin }
```

## 9. 성공 지표 (4주 뒤 측정)

"재미있는 앱"은 측정할 수 없으므로 숫자로 고정한다.

1. 채이가 **부모가 시키지 않고 켠 날** 수 — 목표 4주간 10일 이상
2. 곱셈구구 평균 응답시간 — 5초 → **3초 미만**
3. 세션 완주율 — **80% 이상**
4. 마스터한 단 — 8단 중 **5단**

1·2·3은 부모 화면에서 바로 읽을 수 있고, 백업 JSON에 원자료가 들어 있다.

## 10. 로드맵

**1차 (완료)** — 곱셈구구 + 받아올림·받아내림, SRS, 부모 리포트, PWA

**2차 — 영어.** 여기서 가장 흔한 오해를 먼저 정리해 둔다.

- 공교육 영어는 **초3부터**다. 채이는 **영어 글자를 못 읽는 전제**로 설계해야 한다.
- 말해보카식 단어 암기는 대상 연령이 한참 위다. 가져올 수 있는 건 간격 반복과 세션 구조뿐.
- 초2 영어 = 파닉스(자모 소리) + 사이트워드(Dolch pre-primer 약 40단어) + 듣고 고르기.
- **지시문과 보기를 전부 음성으로 내보내야 한다.** 단어마다 오디오와 그림이 필요해
  수학 대비 공수 약 5배. 여기가 이 앱이 죽을 수 있는 지점이다.
- 오디오는 Web Speech API(무료, 기기 내장 TTS)로 시작하고, 품질이 부족하면 녹음으로 교체.

**3차** — 시각과 시간(아날로그 시계 UI), 길이, 표와 그래프

**언제든** — 채이 옆에서 5분 관찰. 기획서 10장보다 낫다.

## 11. 실행과 검증

```bash
# 로컬 실행
python3 -m http.server 7777
# → http://localhost:7777/chaei/

# 로직 테스트 (브라우저 없이, 36개)
node chaei/test/logic.test.mjs

# 브라우저 테스트 (온보딩→세션→중단복구→결과→부모→PWA→오프라인)
```
